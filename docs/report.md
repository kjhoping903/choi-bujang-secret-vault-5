# T05 공개 비교 보고서 — 초안

## 첫 기능과 후속 기능
GET /api/health는 200과 {status: ok, service: notes}를 반환한다. GET 이외는 405로 거부한다.
자료·사용자 정보·환경변수 값을 반환하지 않는다.
후속 서버 상태 확인 버튼은 200과 정확한 JSON을 확인하며 중복 클릭 방지·5초 시간 초과·재시도를 제공한다.
두 기능은 같은 대화에서 개발했다. 후속 작업을 독립 Session B로 계산하지 않는다.

## 재현
1. A 기능 커밋을 체크아웃한다. 최종 SHA는 아직 미기록이며 시작 커밋과 구분한다.
2. npm.cmd ci
3. npm.cmd run test:t05
통과: tests 10, pass 10, fail 0. 실패: not ok, assertion 오류 및 0이 아닌 종료 코드.
추가 UI 검사: node --test test/health-status.test.mjs.

## AI와 내 판단

## 공개 제출 준비
공개 보고서 HTTPS URL·전체 해시가 포함된 소스 URL·인증 없는 접근: 미확인.
비공개 저장소를 승인 없이 공개 전환하지 않는다.
배포 후 자료실의 서버 상태 확인 버튼을 눌러 서버 응답 정상 표시를 별도로 확인한다.
업로드는 최대 10개·8MB와 허용 형식을 제출 화면에서 확인한다. B 로그는 독립 세션에서 작성한다.

## 기능 1·2 통합 비교 보고서 — 최신 초안

### 개요
기능 1은 서버 상태 확인 버튼이며 기능 2는 배포 버전 API와 하단 배지다. 두 기능은 로그인이나 DB 접근 없이 서버 응답과 공개 배포 식별 정보만 확인한다.

### 방법: Session A와 Session B
A가 구현·검사와 인수인계서를 작성하고, 독립 B는 그 문서와 동일 기능 커밋만으로 재개한다. 현재 실제 작업은 같은 대화의 연속 작업이며 독립 B는 미실행이다.
사용자 승인에 따라 기존 health API 10개는 보존했고 전체 기능 범위 F01~F10은 별도 정의했다. 자동 단위 검사와 실제 계정·DB 수동 검사를 구분한다.

### 측정 항목
F01~F10 통과 수, V1~V5 추가 검사, 실행 명령·종료 코드·Node 버전·검사 파일 해시, 채워진 인수인계 7항목을 기록한다.
B의 재개 시간·질문 수·전체 작업 시간·서비스와 모델 표시 ID는 미측정이다. 검사 실행 시간과 작업 시간을 혼동하지 않는다.

### 한계
실제 계정·DB 재시작·브라우저·Vercel 배포와 공개 URL 검증은 미실행이다. B 비교는 미측정이다. 전체 검사 첫 실패는 수정하지 않은 탐지 연습이며 다른 실패도 보존했다.
화면 실패가 로그인과 서버 상태 버튼을 막지 않도록 독립 모듈로 작성하고 그 동작을 자동 검사했다. 실제 브라우저에서의 결과는 아직 확인하지 않았다.

### 결론
두 기능의 로컬 구현과 개별 검사는 완료했으나 전체 회귀 검사와 독립 인수인계 비교는 완료하지 않았다. 배포 성공이나 과제 전체 통과를 주장하지 않는다.

## 복사본 재검증 — 2026-10-13 최신 초안

### 개요
기능 1과 기능 2가 포함된 기존 커밋 73a4747을 승인된 과제 폴더로 복사하고 검증했다. 이번 실행에서는 기능 코드를 다시 작성하지 않았다.

### 방법: Session A vs Session B
사용자가 승인한 기존 F01~F10을 유지한다. 이번 실행은 A 기록의 보완이며, 인수인계서만 제공받는 독립 B 실험이 아니다. 과거 기록은 보존하고 최신 재검사 로그를 구분한다.

### 측정 항목
고정 F 검사와 추가 V 검사 통과 수, 명령별 종료 코드와 원본 출력, 인수인계 7항목을 기록한다. B 재개 시간·질문 수·통과 수와 A/B 전체 작업 시간은 미측정이다.

### 결과
F07/F09/F10 통과, 나머지 7개 미실행이다. V1~V5는 5/5 통과. 버튼 5/5, 배지 3/3, 기존 health 10/10 통과. 전체 node --test는 37 통과·5 실패다. 근거는 evidence/recheck-verification.json과 recheck-*.log다. 과거 '미커밋' 설명과 달리 복사본의 기능 코드는 이미 커밋되어 있었다. 이번 문서 변경은 미커밋이다.

### 한계
실제 계정·DB 보존·브라우저·Vercel 배포 검증은 미실행이다. 기존 전체 검사 실패를 수정하지 않았다. 독립 B 및 동일 조건 비교는 미측정이다. 실제 실행되지 않은 수동 검사 결과를 통과로 기록하지 않았다.

### 결론
두 기능의 개별 로컬 검사는 통과했다. 전체 회귀 검사 실패와 수동 검사 미실행이 남아 있어 과제 전체 통과와 인수인계 효과는 아직 입증되지 않았다.
